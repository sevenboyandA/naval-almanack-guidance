# 判断力篇：增强判断力（第二章）

> 来源：《纳瓦尔宝典》第一部分第二章"增强判断力"。

## 一、判断力为何重要

- "努力的作用被大大高估了。在现代经济中，工作的努力程度并没有那么重要。"
- "那什么被低估了呢？判断力。判断力被低估了。"
- "在杠杆时代，一个正确的决策可以帮你赢得一切。"
- "在前进的过程中，方向比速度更重要，特别是运用了杠杆以后。在每个岔路口选对方向，其重要程度要远远超过前进的努力程度。"
- 决策的杠杆效应："一个决策正确率为80%的人比正确率为70%的人在市场上的价值和获得的回报要高出数百倍。"

## 二、判断力的定义与清晰思考

- 定义："**智慧是'知道个人行为的长期后果'**，用于解决外部问题的智慧其实就是判断力。"
- "与'聪明'相比，'思路清晰'是一种更好的赞誉。"
- 费曼学习法：真正聪明的人能把事情深入浅出地讲给孩子听；若不能用简单语言解释，说明还没真正理解。
- 基础 > 花哨："一个领域的最新概念往往是没有经过充分验证的……更重要的是牢牢掌握基础知识。""在基础知识层面得90分或100分远胜于盲目地深入钻研。"
- 思考需要空闲："如果每一天都被各种会议占满，都是忙忙碌碌的，你就无法进行思考。""悠闲的大脑才能产生伟大的创意。""我鼓励大家每周至少花一天时间来思考。"

## 三、看清现实：摆脱自我

- "阻碍我们看清现实的最大因素就是我们对现实'应有的样子'有先入为主的印象。"
- 痛苦的定义："当你看到事物的真面目不是你本来想要的样子时，你是痛苦的。""所谓痛苦，就是无法继续无视事实。"
- "要看清真相，就必须摆脱自我，因为自我不想面对真相。"
- 应对：承认问题、开诚布公，对任何人都没有隐瞒时，就不用再欺骗自己。
- 习惯的束缚：习惯与自我认知捆绑；持续成长需打破条件反射，梳理每个习惯的来源与价值。
- 标签与立场："任何划分阵营和贴标签的行为都会给人造成束缚，让人看不清真相。"
- "有求皆苦，无求乃乐。"

## 四、决策技巧（可直接套用的规则）

1. **如果难以抉择，那答案就是否定的**："现代社会充满了选择……如果难以抉择，答案就是否定的。"（适用于结婚、接 offer、买房、搬家、选生意伙伴等）
2. **迎难而上**："如果在一个艰难的决定上意见不统一，你就应该选择短期内更痛苦的道路。""根据复利效应，长期收益才是你想要的。"（大脑本能回避短期痛苦，需自我训练压制）
3. **长期视角**："要选择从长期来看让我们受益最大的做法，而不是只顾眼前得失。"
4. **极度诚实**：费曼"不要欺骗自己，你自己才是最容易被欺骗的人"；诚实是自由的表现。
5. **具体表扬，泛泛批评**（巴菲特建议）：批评针对方法或行为，不针对个人；表扬找到具体的榜样。
6. **逆向思考**："我努力的方向是逐一排除不奏效的方法。我认为成功就是不犯错。"
7. **重大决定多花时间**："最重要的是，要在重大决定上花更多时间。人生早期有三个重大决定：在哪里生活，和谁在一起，从事什么职业。"

## 五、心智模型（判断力的工具箱）

- **进化论**：现代社会的很多现象可用进化论解释。
- **博弈论 / 委托-代理问题**：委托人（主人翁）做得更好，代理人追求自身利益最大化。对策：增加报酬与创造价值之间的相关性，让每个人觉得自己是委托人。
- **复利效应**："如果以每年30%的复利率计算，连续30年，最终得到的不是本金的10倍或20倍，而是数千倍。"
- **基础数学**：算法、概率论、统计学（而非微积分）；"如果要赚钱或者投资，你就必须学好基础数学。"
- **黑天鹅 / 尾部事件**：塔勒布；极端概率事件不可预测，需建立应对不确定性的系统。
- **可证伪性**："如果不能做出可证伪的预测，那就不是科学。"
- **复杂性理论**：承认人类知识有限、极不善于预测未来；打造可在信息盲点下正常运作的系统。

## 六、学会热爱阅读（判断力的养料）

- "每天花一个小时阅读科学、数学和哲学类书籍，7年内，你就可能跻身少数的成功人士之列。"
- "阅读数学、科学和哲学领域的经典作品。不要读畅销书，不要看新闻。……把真理置于社群认同之上。"
- 阅读方法：读喜欢的题材直到热爱阅读；把书当博客跳读，不喜欢就放下；"阅读是在锻炼精神的肌肉"。
- 打基础：从基础学科和原著读起（先读达尔文再读道金斯；先读亚当·斯密再读解读）。
- 输出内化："向别人讲解你学到的东西。教学相长。"
- 古老问题："问题越古老，解决方案存在的时间越长。""任何流传了两千年的图书都经过了许多代人的甄别和筛选。"（健康、内心平静、家庭、价值观——读古人的书）

## 七、典型回答模板

- **"A 和 B 怎么选？"** → 先问是否"难以抉择"：是 → 答案是"否"（选择很多，犹豫说明没有压倒性理由）；两难时 → 选短期更痛苦但长期回报更大的路；重大决定 → 值得专门花时间思考，列出长期后果。
- **"我总想不清楚/很混乱"** → 放下自我评判 → 第一性原理拆解 → 每周留思考时间 → 从基础学科建立框架 → 读经典。
- **"怎么提高判断力？"** → 阅读 + 心智模型 + 诚实面对现实 + 练习在难抉择时说"不"。
